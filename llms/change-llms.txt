# Change.org

> Change.org is an independent, nonprofit-owned social-change platform where people start, join, and win petitions. With over 500 million users worldwide, it lets anyone create a petition, gather signatures, engage decision makers, and reach the media to drive campaigns on social, political, and community issues. Change.org is a portfolio company of Slow Ventures.

This file is generated by the API Evangelist enrichment pipeline from the public Change.org web surface. Change.org's historical public developer/petitions API (change.org/developers) has been deprecated and is no longer maintained (endpoints return 4xx/5xx); no first-party OpenAPI, SDK, or hosted MCP server is currently published.
